bramble

Project spliced genomic alignments into transcriptomic space, enabling transcript quantification to work with genomic alignments.

C++ Rust MIT License

bramble takes reads aligned to a genome, together with a reference annotation, and rewrites each alignment in transcript coordinates, once for every annotated transcript the alignment is compatible with. The result is a transcriptome BAM that alignment-based quantifiers such as salmon and oarfish read directly.

This means you can align your reads once, to the genome, with any spliced aligner (for example HISAT2 or STAR for short reads, or minimap2 for long reads), and use the same alignments both for genome-based analyses and for transcript quantification. bramble has presets for short reads and for long reads of different accuracies.

How it works

For each alignment, bramble finds the annotated exons that its aligned blocks (the read exons) overlap. A transcript is compatible when the read exons line up with consecutive exons of that transcript and every exon boundary matches the annotation, within tolerances that depend on the read type. For every compatible transcript, bramble writes one record, with its position and CIGAR string in transcript coordinates. The two mates of a read pair are placed together on a transcript they share.

Long reads need more tolerance than short reads, because sequencing errors near a splice junction often shift where the aligner puts the exon boundary. The read-type presets set these tolerances for you.

Versions

bramble is available as a C++ executable (bramble) and a Rust executable (bramble-rs). Both take the same options and produce the same alignments; the Rust version has a few extra options. The Rust library at the core of the Rust version, bramble-rs, can be built into other programs, and bramble is also available directly inside salmon and oarfish.
