bramble

Project spliced genomic alignments into transcriptomic space, enabling transcript quantification to work with genomic alignments.

C++ Rust MIT License

bramble works with any alignment method and any quantification method that can use alignments as input, with several modes optimized for different short- and long-read sequencing technologies. It's available as a standalone executable in either C++ or Rust, as a library in Rust, or directly in salmon or oarfish.
