Required arguments

Every run needs an input BAM, an annotation, and an output path.

bramble <in.bam> -G <annotation.gtf> -o <out.bam> [options]

The options are explained on the pages of this section: read-type presets, boundary tolerances, long-read options, clip rescue, strandedness, and threads and other options.

<in.bam>

positional, required

The reads aligned to the genome, in BAM format, from any spliced aligner. All records of a read must be next to each other (see Quick start): bramble projects every mapped record of a read, including secondary alignments, and then decides together which of the read's projections become primary and how they pair up. Unmapped records are skipped.

-G, --guide <file>

required

The reference annotation, in GTF or GFF3 format. Its transcripts are the targets reads are projected onto: each one becomes a reference sequence of the output BAM, named by its transcript ID, with the length of its spliced exons. The chromosome names in the annotation must match those in the BAM. Use the same annotation to build the transcript sequences for your quantifier, so the names match.

-o, --out <file>

required

Where to write the projected alignments, as a BAM file. The Output section describes what it contains.
