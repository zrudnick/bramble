Threads and other options

Threads, logging, and the Rust-only options.

-p, --threads <int>

default: 1

The number of threads to use. Each read's records are always written together and in the same order, but with more than one thread the C++ version may write reads in a different order from run to run. The Rust version keeps the input order unless you ask for --unordered.

-q, --quiet

Turns off the progress messages bramble prints while it runs.

-V, --version

Prints the version and exits.

-h, --help

Prints the list of options and exits.

Rust-only options

These options are available only in bramble-rs, not in the C++ bramble.

--unordered

Each thread writes its output as soon as it's ready, instead of in input order. This is faster with -p greater than 1, but the order of reads in the output changes from run to run. The alignments of a read stay together.

--unordered-flush-records <int>

default: 1024

With --unordered, the number of records each thread collects before writing them.
