Quantifying existing genome BAMs

Reusing genome alignments you already have, including public ones, without realigning.

If you already have reads aligned to the genome, you can quantify transcripts from them directly: bramble projects the alignments and a quantifier takes it from there, with no need to go back to the FASTQ files.

What bramble needs from the BAM

  • Alignments from a spliced aligner, such as STAR, HISAT2, or minimap2.
  • The records of each read next to each other (see below).
  • Ideally, the secondary alignments of reads that align to several places. If they were filtered out, bramble still runs, but those reads are only projected from the alignment that was kept.

What the BAM doesn't contain can't be recovered: reads the aligner left unmapped, and alignments it never reported.

Find the genome build

The annotation must be for the same genome build the reads were aligned to. The BAM header usually tells you: the @PG lines show the aligner command (often with the index name), and the @SQ lines give chromosome lengths. 

samtools view -H genome.bam | grep '^@PG'
samtools view -H genome.bam | grep '^@SQ' | head -3

For human, chr1 is 248,956,422 bases long in hg38 (GRCh38) and 249,250,621 in hg19 (GRCh37).

Match the chromosome names

The annotation must name chromosomes as the BAM does. UCSC and GENCODE use chr1, Ensembl uses 1, and the mitochondrial genome is chrM in one and MT in the other. If the BAM uses chr1 and the annotation uses 1, add the prefix: 

awk 'BEGIN {FS = OFS = "\t"} /^#/ {print; next} {$1 = ($1 == "MT" ? "chrM" : "chr" $1); print}' \
  annotation.gtf > annotation.chr.gtf

Check the result against the BAM's @SQ names; unplaced contigs and patches are named differently between sources, and reads on them won't project if the names don't match.

Prepare the BAM

Public BAMs are usually sorted by coordinate, which separates each read's records. Collate them first: 

samtools collate -@ 8 -o genome.collated.bam genome.bam

Run bramble and quantify

  • Choose the preset from the sequencing technology in the data's metadata; see Choosing a preset.
  • For short reads, find out whether the library is stranded, from the protocol or from the data; see Stranded libraries.
  • Then follow the short-read or long-read guide from the bramble step on.
