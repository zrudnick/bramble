Guides

Complete workflows with bramble.

These guides go further than the Quick start: whole analyses from raw reads to quantities, and advice for particular kinds of data. The two start-to-finish guides run on a small example data set that comes with bramble (example/ in the repository), and so does the StringTie guide.

Workflows

  • Short reads, start to finish: STAR or HISAT2, bramble, salmon.
  • Long reads, start to finish: minimap2, bramble, oarfish.
  • Quantifying existing genome BAMs: reusing alignments without realigning.
  • Sample-specific annotations with StringTie: assemble, then project.

Your data

  • Incomplete annotations and non-model organisms
  • Choosing a preset and tuning tolerances
  • Stranded libraries
  • Single-cell and UMI data
