Stranded libraries

Telling bramble, and your quantifier, which strand short reads come from.

In a stranded library, each read comes from a known strand of the transcript. Telling bramble lets it skip transcripts on the other strand, which matters where genes overlap on opposite strands. This applies to short reads only: for long reads, bramble always checks both strands.

Is my library stranded, and which way?

The kit usually tells you. Most stranded short-read kits are based on dUTP and produce fr-firststrand data, where read 1 is the reverse complement of the transcript; Illumina TruSeq Stranded is one of them. Some kits produce fr-secondstrand data, where read 1 has the transcript's sequence. If you're not sure, check the data, in any of these ways:

  • salmon: run it with -l A; it reports the library type it detected in logs/salmon_quant.log.
  • RSeQC: infer_experiment.py reports the fraction of reads on each strand of known genes.
  • bramble itself: run it on a sample with --fr and with --rf, and count the reads that project (samtools view -c -F 0x904 transcriptome.bam). The right flag projects far more: in bramble's forward-stranded example data, 69,588 reads project with --fr against 21,441 with --rf.

Setting the flags

fr-firststrand, e.g. dUTP--rfRF (single-end R)--rfISR (single-end SR)
fr-secondstrand--frFR (single-end F)--frISF (single-end SF)
unstrandedneitherdefaultdefaultIU (single-end U)

The flags mean the same in bramble, HISAT2 and StringTie. For single-end reads, the read counts as read 1.

What changes in the output

  • Reads are only placed on transcripts on their own strand, so a read in a region where genes overlap on opposite strands no longer counts toward both.
  • Reads that carry a strand tag from the aligner (XS, or minimap2's ts) use the tag instead of the flag; in practice the flag decides the strand of unspliced reads.
  • With the wrong flag, most unspliced reads are checked only against the wrong strand, so far fewer reads project. A sudden drop in the fraction of reads that project is the sign to check the flag.
