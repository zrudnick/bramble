Installation

Install from Bioconda, build the C++ version, or install the Rust crate.

Bioconda

conda install -c bioconda bramble

This installs the Rust version. Both bramble and bramble-rs run it, so the commands in these docs work as written.

C++

bramble uses the meson build system. System dependencies are required for zlib, bz2, and lzma (meson will try to build zlib and bz2 via wrapdb if they aren't found on the system). You'll also need meson, ninja, and autotools installed.

Run build.sh directly, or build manually:

meson setup build
cd build
ninja

This produces the bramble executable. Tested with meson 1.7 and 1.8 (likely works with older versions too).

Rust

cargo install bramble-cli

This builds against the system htslib prerequisites (zlib, bzip2); a C compiler and libclang (for bindgen) are required at build time.

The installed executable is named bramble-rs. The crate is called bramble-cli only to tell it apart from the library on crates.io. bramble-cli is the command-line front end: it adds the htslib-backed BAM reader and writer, threading, and the command-line interface to the library.

Rust library

bramble-rs is the Rust library at the core of bramble. It is I/O-free: it has no dependency on htslib or rust-htslib. You bring the alignments (from rust-htslib, noodles, minimap2-rs, etc.) as plain structs, and bramble returns projected alignments as plain structs. See the bramble-rs README for usage examples.
